# Security Policy

## Supported Versions

Predictron Engine is currently under active development.

Security updates are provided for the latest development version.

| Version | Supported |
|---------|:---------:|
| Latest | ✅ |
| Older versions | ❌ |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately rather than opening a public issue.

Include the following information whenever possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Proof of concept (if applicable)
- Suggested mitigation (optional)

Reports will be reviewed as quickly as possible.

---

## Disclosure Policy

Please avoid publicly disclosing security vulnerabilities until they have been investigated and, where appropriate, addressed.

Responsible disclosure helps protect users and maintain the integrity of the project.

---

## Scope

This policy applies to the Predictron Engine codebase, including:

- Core intelligence engine
- Extraction modules
- Reasoning framework
- Evidence framework
- Benchmarking infrastructure
- Documentation where security implications exist

---

## Security Principles

Predictron Engine is developed with the following security principles in mind:

- Least privilege
- Secure defaults
- Defense in depth
- Reproducible engineering
- Continuous testing
- Responsible disclosure

As the project evolves, additional security practices and automated validation will be incorporated into the development workflow.
