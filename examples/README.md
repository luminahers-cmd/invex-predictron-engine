# Examples

This directory contains example inputs and outputs demonstrating how Predictron Engine transforms startup information into structured venture intelligence.

The examples are intended to illustrate the overall workflow rather than represent production evaluations.

## Contents

- **sample_input.md** — Example startup information provided to the engine.
- **sample_report.md** — Example venture intelligence report generated from the input.

These examples are simplified for documentation purposes and may not reflect the complete capabilities of the engine.
